## Reading the photograph

- Upper left shows the USB-connected controller and expansion board.
- Centre shows the breadboard, jumper wires, indicator LEDs and interface boards.
- Lower left shows the blue temperature and humidity sensor module.
- Lower centre shows a sensor board viewed from its underside. Its model needs a readable label photograph.
- Centre right shows the two-prong soil probe.
- Far right shows the rain detection plate.

The photograph documents the physical assembly. It does not establish continuity, supply voltage, resistor resistance, calibration, installed firmware or successful uploads. Compare the actual wiring with D-02 before treating the draft as verified. Both red and green LED packages are visible, so the single-LED draft needs reconciliation with the hardware owner.

Still needed are module-label close-ups, measured electrical values, firmware identification and a correlated serial reading, database row and dashboard alert. Record disconnect and reconnect outcomes separately.
